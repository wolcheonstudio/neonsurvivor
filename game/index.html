GAME FEATURES

자동 조준 시스템

가장 가까운 적을 자동으로 포착하여 전술적 우위를 점하세요.

무한 성장

레벨업마다 무기 데미지와 기동성을 강화할 수 있습니다.

거대 보스전

10레벨마다 등장하는 강력한 보스를 처치하고 특별 보상을 받으세요.

집중 포화 (Z키)

이동 속도를 줄이는 대신, 탄환 크기와 데미지를 극대화하여 적을 섬멸합니다.

실시간 무기 교체 (Q키)

보유한 무기를 실시간으로 교체하여 상황에 맞는 최적의 전술을 구사하세요.

모바일 전용 터치 조작계

좌측 가상 조이스틱으로 자유롭게 비행하고, 우측 터치 버튼으로 무기교체·집중포화·앰플회복을 즉시 시전하세요!

풀스크린 와이드 최적화

스마트폰 가로 모드에 빈틈없이 꽉 들어찬 16:9 와이드 비율로 검은 여백 없는 몰입감을 만끽하세요.

조작 방법

WASD, 방향키: 이동
Z: 집중 포화 | Q: 무기 교체
Space: 회복 앰플 | Enter: 일시정지
